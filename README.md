# CinePedia

Este proyecto trata de una aplicacion web llamada CinePedia desarrollada con Python y Flask para gestionar, peliculas. La idea principal es que los usuarios puedan registrarse e iniciar sesion para compartir sus peliculas favoritas, ver las de otros y comentar.

## De que trata la aplicacion

La plataforma permite realizar las siguientes acciones:

* **Registro e Inicio de Sesion**: Los usuarios pueden crear una cuenta con sus datos y acceder de forma segura.
* **Dashboard de Peliculas**: Se muestra una lista completa con las peliculas registradas, su director y la fecha de estreno.
* **Agregar y Editar**: Cada usuario puede publicar una nueva pelicula, agregando su titulo director, fecha y sinopsis. Solo el creador de la pelicula puede editarla o borrarla.
* **Detalle y Comentarios**: Al seleccionar una pelicula se despliega toda su informacion incluyendo quien la publico. Ademas los usuarios pueden dejar comentarios en las peliculas de otros y borrar, sus propios comentarios.

## Tecnologias utilizadas

* **Backend**: Python con Flask y Jinja2
* **Base de Datos**: MySQL
* **Frontend**: HTML5 y CSS3
